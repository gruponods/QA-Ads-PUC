Round icon-only button for app toolbars, topbars and table row actions. Always pass `label` (used for aria-label and tooltip).

```jsx
<IconButton icon="bell" label="Notificaciones" badge />
<IconButton icon="dots-vertical" label="Más acciones" size="sm" />
<IconButton icon="plus" label="Agregar" variant="primary" />
```

Variants: `ghost` (default, gray hover) · `outline` (hairline → blue on hover) · `primary` (blue fill). Sizes 32 / 40 / 48px.
