Pill-shaped tag / chip for categories, statuses, and metadata. Always fully rounded, uppercase micro-label.

```jsx
<Tag>Beta</Tag>
<Tag variant="soft" icon="sparkles">IA</Tag>
<Tag variant="solid">Nuevo</Tag>
```

Variants: `outline` (default, hairline border) · `soft` (light-blue chip, blue text) · `solid` (blue fill, white text — use sparingly) · `neutral` (gray).
