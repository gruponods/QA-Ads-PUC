Two separators, nothing else. `rule` is a 1px hairline (#E5E7EB) for dividing content; `accent` is a short blue bar used under headlines and kickers.

```jsx
<Divider variant="accent" length="56px" />
<Divider />                       {/* full-width hairline */}
<Divider vertical length="40px" /> {/* hairline column separator */}
```

Use the accent bar to punctuate a headline; use the hairline rule to separate rows, table headers, and footer zones.
